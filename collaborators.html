For Collaborators

Overview

In Vero Vacuo welcomes collaboration with researchers working on vacuum metastability, semiclassical decay processes, lattice methods, and gauge-theory structure. The project provides a complete, validated computational framework for fluctuation-determinant evaluation in scalar and SU(2) gauge theories.

What I Provide

  • Validated SU(2) lattice determinant pipeline
  • Scalar-sector determinant tools
  • Higgs Fluctuation Solver
  • Determinant Ratio Calculator
  • SHA‑256 reproducibility archives
  • Technical documentation and report bundles

What I’m Looking For

  • Finite-temperature tunneling studies
  • Multi-field potentials
  • Curved-spacetime backgrounds
  • Gauge theories with nontrivial structure
  • Early-universe phase transitions
  • Higgs-sector metastability analysis

Collaboration Workflow

  1. Problem definition — identify the physical setting.
  2. Operator construction — build scalar/gauge Hessians.
  3. Determinant evaluation — SLQ trace-log methods.
  4. Matching and comparison — lattice–MS checks.
  5. Joint reporting — prepare technical documentation.
